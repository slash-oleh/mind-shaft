## Product

- Brief: Mind Shaft is an agentic engineering handbook - a monorepo of rules and processes for AI coding agents, distributed to other projects and published as a docs site.
- References: `README.md` (repo overview), `CONTRIBUTING.md` (contribution guide), `docs/` (site source), published site linked from `README.md`.

## Terminology

- **Skill**: Agent skill. An automated workflow for an agent (`packages/skills`).
- **Rule** (also "Article"): Agent rule. An enforced best practice (`packages/rules`). Short AI Rules are generated from full articles.
- **Stack**: Toolset reference material (`packages/stack`).
- **Skill Group** (also "Skill Category"): A subdirectory grouping related skills under `packages/skills/src/` (e.g. `generic`, `meta`, `sdlc`, `tools`, `workflows`).
- **Target**: An AI tool that rulesync generates config for (e.g. Claude Code, Cursor).

## Structure

- Breakdown:
  - `packages/rules` (`@mind-shaft/rules`): best-practice rule sources.
  - `packages/skills` (`@mind-shaft/skills`): skill sources.
  - `packages/stack` (`@mind-shaft/stack`): toolset reference sources.
  - `packages/cli` (`@mind-shaft/cli`, bin `mind-shaft`): installs rules/processes into another project.
  - `ai/`: generated output consumed by the npm package (committed, not hand-edited).
  - `.rulesync/`: rulesync's own rule/process sources for this repo (this file is the root entry). `.claude/`, `.cursor/`, `.agents/`: per-tool configs generated by rulesync.
  - `docs/`, `zensical.toml`: documentation site source and config (Zensical).
- Dependencies: `packages/rules` and `packages/skills` each build into `ai/rules` and `ai/skills` via their own `build:ai` scripts. `packages/cli` distributes those `ai/` folders. The docs site (`docs/`) aggregates content from all three packages. rulesync reads `.rulesync/` and writes the per-tool targets (`.claude`, `.cursor`, `.agents`, root `AGENTS.md`, etc.).

## Stack

- Hosting: GitHub Pages for the docs site, deployed via `.github/workflows/pages.yml` on push to `main`.
- Languages: JavaScript (Node ESM), Markdown.
- Tools: npm workspaces, remark (markdown lint), Prettier (format), cspell (spellcheck), Zensical (docs site builder), rulesync (rule/process distribution to AI tool configs), Docker Compose (local docs preview).
- Runtime: Node.js, no pinned version file. CI docs build uses Python 3.x for Zensical; the manual lint container uses `node:20-slim`.
- Globals: Docker, for `docker compose up` docs preview.

## Code quality

- Formatter: Prettier (`.prettierrc`).
- Run: `npm run lint`, `npm run lint:fix`, `npm run spellcheck`.
