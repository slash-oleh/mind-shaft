# Phase 1: Gather Info

## Goal

- All raw task specifications, design links, documentation retrieved
- Relevant codebase locations are identified.

## Steps

### Step 1: Use Gathered Task Info

Use `gather-task`'s output - assume it already ran earlier this session, or was supplied as input.

## Output

Same as `gather-task`'s output:

- Ticket: ID, if resolved.
- Task: Title and description.
- Linked Resources: List of URLs/IDs and summaries.
- Affected Modules: List of directories/files likely affected.
- Existing Patterns: List of similar/reusable code locations.
